## 📈 Projeto 1: Sistema de Precificação

### Antes vs Depois

```
ANTES (Sem Sistema)
├─ 18% vendas com prejuízo ❌
├─ Margem inconsistente
├─ Decisões manuais (erro humano)
└─ Resultado: Perdendo dinheiro

DEPOIS (Com sistema híbrido: automações low-code e scripts auxiliares)
├─ 0% vendas com prejuízo ✅
├─ Margem garantida
├─ Cálculo automático
└─ Resultado: +150% de margem garantida

┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃  IMPACTO FINANCEIRO                ┃
┃  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ┃
┃  Prejuízo eliminado:  -18% → 0%    ┃
┃  Margem adicional:    +150%        ┃
┃  Tempo/venda:        -80% (automático)
┃  ROI:                 342% em 2 meses
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
```

### Fórmula utilizada
```python
Preço Venda = Custo / (1 - Taxa Total - Margem Desejada)

Exemplo:
- Custo: R$ 100
- Taxa marketplace: 13.9% (Mercado Livre)
- Margem desejada: 30%
- Resultado: R$ 223,95 (garantindo 30% de lucro)
```
